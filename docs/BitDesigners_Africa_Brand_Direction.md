# BitDesigners Africa --- Brand Direction

## Brand Personality

BitDesigners Africa should feel:

-   Serious
-   Technical
-   Modern
-   Intentional
-   Premium
-   Design-forward
-   High signal
-   Calm and confident

It should **not** feel playful, overly gamified, or like a typical
crypto project.

Our positioning is unapologetically **Bitcoin-only**. No meme coins, no
altcoins, no crypto culture.

The visual language should communicate professionalism, craftsmanship,
and trust while embracing modern product design standards.

------------------------------------------------------------------------

# Design Principles

Aim for a design language inspired by products like:

-   Linear
-   Raycast
-   Vercel
-   GitHub
-   Notion
-   Figma
-   Bitcoin Design Guide

Avoid cyberpunk aesthetics, excessive Bitcoin-orange, loud gradients,
and flashy animations.

------------------------------------------------------------------------

# Typography

## Preferred

### Headings

**Geist**

Reasons: - Modern - Technical - Premium - Excellent for product
interfaces

### Body

**Inter**

Reasons: - Extremely readable - Mature UI font - Open source - Excellent
for long-form educational content

### Alternatives

-   IBM Plex Sans
-   General Sans
-   Söhne (commercial)

# Bitcoin Accent

Use sparingly.

``` text
#F7931A
```

Recommended uses:

-   Bitcoin references
-   BTC balances
-   Rewards
-   Bitcoin-specific badges

Avoid making this the primary UI accent.

# Color Meaning

  Color             Meaning
  ----------------- --------------------
  Orange            Bitcoin
  Indigo / Blue     Learning & Product
  Purple (future)   AI
  Green             Completion
  Red               Issues / Errors

This consistent semantic system improves usability and recognition.

------------------------------------------------------------------------

# Component Style

## Cards

-   Rounded corners (12--16px)
-   Subtle borders
-   Minimal shadows

## Buttons

-   Solid fills
-   No gradients
-   Clear hierarchy

## Borders

-   Thin (1px)
-   Low-contrast

## Spacing

-   Generous whitespace
-   Comfortable reading rhythm
-   Clean layouts

------------------------------------------------------------------------

# Motion

Motion should be restrained.

Think Linear, not crypto landing pages.

Use animation only to communicate:

-   State changes
-   Navigation
-   Feedback
-   Progress

------------------------------------------------------------------------

# Imagery

Prioritize:

-   Product screenshots
-   Figma files
-   UX diagrams
-   Wireframes
-   Flowcharts
-   Educational illustrations

Avoid:

-   Coins everywhere
-   Candlestick charts
-   Generic crypto graphics

------------------------------------------------------------------------

# Brand Statement

> **BitDesigners Africa is where premium product design meets Bitcoin
> engineering culture.**

Every visual and interaction should reinforce that members are joining a
serious, world-class community of designers contributing to the future
of Bitcoin.
